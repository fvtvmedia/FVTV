# Security and sensitive information

This repository is public. Do not commit passwords, API keys, session cookies, private contact databases, confidential agreements, payment information, unpublished personal data, or private partner correspondence.

If sensitive information is accidentally committed, rotate or revoke it immediately, remove it from repository history where appropriate, and notify the repository owner through the private FVTV channel. Do not open a public issue containing the secret or confidential content.

For operational privacy questions, use the approved FVTV CRM or private project system rather than this repository.
