# Legacy GitHub Deliverable Index

The original issue-based business deliverable index is archived as historical repository state. It is **not** the live FVTV operating queue.

Current unfinished business work is controlled by the Notion **Nia Work Queue**, with provider state verified in Gmail, Google Drive, Metricool, Calendly, StreamYard, accounting ledgers, and other canonical systems.

Existing historical GitHub business issues may be closed as migrated/superseded without implying that the underlying business task itself is complete.

For current repository work, use GitHub issues only for code, workflow implementation, schemas, CI, validators, and technical defects.
