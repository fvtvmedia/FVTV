# Technical Deliverable Control

The former GitHub issue-based business-deliverable model is superseded.

The Notion **Nia Work Queue** is the only unfinished-work queue. Partner work, revenue opportunities, editorial assignments, interviews, follow-ups, applications, and operational commitments belong there.

GitHub tracks only workflow code, schemas, CI, validators, technical runbooks, repository bugs, and implementation-specific technical debt.

Use the shared runtime states: NEW, READY, RUNNING, BLOCKED, WAITING, VERIFYING, REPAIR, DONE, CANCELLED.

A code artifact is not DONE merely because a file was created. Verify branch, diff, validation, and merge state. Operational completion is verified in the canonical private system/provider, not by closing a GitHub issue.
