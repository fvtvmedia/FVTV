# Video Production Contract

Canonical live authority: **FVTV Video Production Entry Point** plus **FVTV Posting Rules v3**.

Current stack: Filmora for edit/assembly/export; ElevenLabs for approved Keylo voice generation only when separately authorized and materially useful; Colab retired; Descript optional; Metricool for scheduler state.

Automatic ChatGPT longform creation and automatic ElevenLabs spending remain held. Direct owner-requested production in a live conversation is a separate authorized lane.

Build sequence: resolve the existing project first; reuse the current Drive folder/edit project/assets; watch source media; choose the first 3–5 seconds and cold open before scripting; build around real source footage/evidence; write only needed bridges; assemble in Filmora; render a private candidate; validate manifest/hashes; review the complete export; deliver review artifacts; release separately.

No title card, generic camera shot, filler montage, or branding before the hook. Crop around the speaker, evidence, or action, not dead UI/empty canvas.

Every release candidate must verify current policy, holds, intended account, scheduler duplicates, first 10 seconds, full playback, transcripts/outputs, and framing. A render/hash check alone is not full audiovisual/editorial review.
